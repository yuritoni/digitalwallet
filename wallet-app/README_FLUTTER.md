# Flutter Wallet App

```bash
flutter create wallet_app
cd wallet_app
```

Copy isi folder `wallet-app` ini ke project Flutter baru, lalu:

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api
```

Android HP fisik:

```bash
flutter run --dart-define=API_BASE_URL=http://IP-LAPTOP:8000/api
```
